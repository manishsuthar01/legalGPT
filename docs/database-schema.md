# LegalGPT — Database Schema & Vector Storage Specification

LegalGPT utilizes **Supabase (PostgreSQL)** paired with the **`pgvector`** extension for persistent contract metadata, document storage, and high-dimensional semantic vector search.

---

## 1. PostgreSQL Extensions

```sql
-- Enable pgvector for semantic clause search
CREATE EXTENSION IF NOT EXISTS vector;

-- Enable UUID generation
CREATE EXTENSION IF NOT EXISTS "uuid-ossp";
```

---

## 2. Relational & Vector Schema

### 2.1. `contracts` Table

Stores top-level metadata for ingested contract documents.

```sql
CREATE TABLE contracts (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    user_id TEXT NOT NULL,
    file_name TEXT NOT NULL,
    file_path TEXT NOT NULL,
    file_size BIGINT,
    mime_type TEXT,
    country TEXT NOT NULL DEFAULT 'United States',
    status TEXT NOT NULL CHECK (status IN ('pending', 'processing', 'completed', 'failed')) DEFAULT 'pending',
    risk_score INTEGER,
    overall_risk TEXT CHECK (overall_risk IN ('LOW', 'MEDIUM', 'HIGH')),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL,
    updated_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Indices for rapid querying by user and status
CREATE INDEX idx_contracts_user_id ON contracts(user_id);
CREATE INDEX idx_contracts_status ON contracts(status);
```

---

### 2.2. `clauses` Table (Vector Store)

Stores segmented contract clauses along with vector embeddings generated by Google Gemini (`gemini-embedding-001` - 768 dimensions).

```sql
CREATE TABLE clauses (
    id BIGSERIAL PRIMARY KEY,
    contract_id UUID NOT NULL REFERENCES contracts(id) ON DELETE CASCADE,
    content TEXT NOT NULL,
    chunk_index INTEGER NOT NULL,
    source TEXT,
    metadata JSONB DEFAULT '{}'::jsonb,
    embedding VECTOR(768),
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

-- Index for filtering clauses by contract
CREATE INDEX idx_clauses_contract_id ON clauses(contract_id);

-- HNSW Vector Index for ultra-fast cosine similarity search
CREATE INDEX idx_clauses_embedding ON clauses 
USING hnsw (embedding vector_cosine_ops)
WITH (m = 16, ef_construction = 64);
```

---

### 2.3. `analysis_reports` Table

Stores finalized legal advisory reports, risk cards, positive findings, and missing clauses.

```sql
CREATE TABLE analysis_reports (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    contract_id UUID NOT NULL REFERENCES contracts(id) ON DELETE CASCADE,
    summary TEXT NOT NULL,
    overall_risk TEXT NOT NULL CHECK (overall_risk IN ('LOW', 'MEDIUM', 'HIGH')),
    risk_score INTEGER NOT NULL CHECK (risk_score >= 0 AND risk_score <= 100),
    risk_score_breakdown JSONB NOT NULL,
    risk_cards JSONB NOT NULL DEFAULT '[]'::jsonb,
    advisor_feedback JSONB NOT NULL DEFAULT '[]'::jsonb,
    reviewer_feedback JSONB NOT NULL DEFAULT '[]'::jsonb,
    positive_findings JSONB NOT NULL DEFAULT '[]'::jsonb,
    missing_clauses JSONB NOT NULL DEFAULT '[]'::jsonb,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

CREATE UNIQUE INDEX idx_analysis_reports_contract_id ON analysis_reports(contract_id);
```

---

### 2.4. `chat_messages` Table

Stores conversation history for the interactive RAG assistant.

```sql
CREATE TABLE chat_messages (
    id UUID PRIMARY KEY DEFAULT uuid_generate_v4(),
    contract_id UUID NOT NULL REFERENCES contracts(id) ON DELETE CASCADE,
    user_id TEXT NOT NULL,
    role TEXT NOT NULL CHECK (role IN ('user', 'assistant', 'system')),
    content TEXT NOT NULL,
    sources JSONB DEFAULT '[]'::jsonb,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now()) NOT NULL
);

CREATE INDEX idx_chat_messages_contract_id ON chat_messages(contract_id);
CREATE INDEX idx_chat_messages_created_at ON chat_messages(created_at ASC);
```

## 3. Vector Similarity Search Function (`match_clauses`)

LangGraph and SupabaseVectorStore invoke the `match_clauses` Remote Procedure Call (RPC) for semantic retrieval:

```sql
CREATE OR REPLACE FUNCTION match_clauses (
    query_embedding VECTOR(768),
    match_count INT DEFAULT 5,
    filter JSONB DEFAULT '{}'::jsonb
) RETURNS TABLE (
    id BIGINT,
    contract_id UUID,
    content TEXT,
    metadata JSONB,
    similarity FLOAT
)
LANGUAGE plpgsql
AS $$
BEGIN
    RETURN QUERY
    SELECT
        clauses.id,
        clauses.contract_id,
        clauses.content,
        clauses.metadata,
        1 - (clauses.embedding <=> query_embedding) AS similarity
    FROM clauses
    WHERE 
        (filter->>'contractId' IS NULL OR clauses.contract_id = (filter->>'contractId')::UUID)
    ORDER BY clauses.embedding <=> query_embedding
    LIMIT match_count;
END;
$$;
```
